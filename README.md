# 시간표 배부용 인쇄 도구

학급 시간표를 붙여넣으면 학생 배부용 인쇄 시트(A4 가로, 여러 장 반복)를 만들어주는 단일 파일 웹 도구입니다.

## 사용법
- `index.html`을 열면 바로 사용할 수 있습니다.
- GitHub Pages로 배포하면 별도 서버 없이 웹에서 바로 접근 가능합니다.

## 기능
- 엑셀·구글시트·나이스 화면에서 표를 복사해 붙여넣으면 자동 인식
- 칸별 직접 수정, 요일/교시 수 조정
- 사본 매수 지정 또는 학생 이름 붙여넣기로 개인용 이름표 생성
- 5가지 디자인 테마 (기본/클래식/파스텔/모노/무지개)
- 인쇄용 A4 가로 레이아웃, 가위 아이콘으로 절취 위치 표시
